# Magic: The Gathering – Template & Asset Repository

Este repositório é uma iniciativa comunitária dedicada à preservação, manutenção e organização de ativos visuais (fontes, ícones, vetores e estruturas de layout) para a criação e restauração de cartões de *Magic: The Gathering*.

## 📁 O que você encontrará neste repositório

- **Símbolos e Ícones:** Vetores e imagens de símbolos de mana e raridades limpos para renderização.
- **Fontes:** Referências tipográficas utilizadas pela comunidade em layouts de cartas.
- **Templates:** Arquivos de estrutura para criação de protótipos de cartões.
